# Giveaway edit and duration update

- The preview Edit button now opens a category selector instead of a three-field modal.
- Edit categories cover basics (prize/duration/winners/channel), role rules (bonus/required/bypass/blocked), eligibility requirements, messages/appearance, and advanced settings.
- Duration accepts human-readable values such as `1h`, `1day`, `1 week`, `56h`, `30m`, and compound values such as `2d 4h`, from 1 minute up to 1 year.
- Updated preview is refreshed after edits.
- Validation performed: all Python files compile and dashboard JavaScript passes `node --check`.
- Live Discord interaction testing has not been performed.
